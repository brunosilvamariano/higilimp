# Recursos visuais

As duas fotografias são ilustrações sintéticas geradas com a ferramenta image_gen em 20/10/2026. Não retratam clientes, equipe, serviços realizados ou resultados reais da Zelora. O logotipo SVG é uma criação vetorial para este projeto. Os prompts e o processo de geração estão registrados no pacote de entrega externo.
